# 4. Token Transfer

## How to transfer Tokens from the Treasury to a Specific Address <a href="#docs-internal-guid-15a95c9f-7fff-446d-05f5-c38d1e2ed56b" id="docs-internal-guid-15a95c9f-7fff-446d-05f5-c38d1e2ed56b"></a>

<figure><img src="../.gitbook/assets/image (67).png" alt=""><figcaption></figcaption></figure>

Choose a token from the treasury. Specify the quantity and insert the recipient's address. Proceed with the standard process of creating a proposal, as described earlier.

Please review your changes one last time before you click "Next." These changes cannot be undone once the proposal reaches the quorum and is executed.

## 1. Select the proposal creation method <a href="#id-2.-select-the-proposal-creation-method" id="id-2.-select-the-proposal-creation-method"></a>

<figure><img src="../.gitbook/assets/image (68).png" alt=""><figcaption></figcaption></figure>

Select if you'll create this proposal directly with your tokens, or use metagovernance delegation.

## 2. Basic proposal info <a href="#id-3.-basic-proposal-info" id="id-3.-basic-proposal-info"></a>

<figure><img src="../.gitbook/assets/image (69).png" alt=""><figcaption></figcaption></figure>

Provide a clear title and comprehensive description so members understand what's being proposed. Review and click "Vote & Create Proposal" to launch the proposal and self-vote.

## 3. Create a proposal <a href="#id-4.-create-a-proposal" id="id-4.-create-a-proposal"></a>

<figure><img src="../.gitbook/assets/image (70).png" alt=""><figcaption></figcaption></figure>

Specify the number of tokens you want to use and confirm the transactions.

<figure><img src="../.gitbook/assets/image (71).png" alt=""><figcaption></figcaption></figure>

Click "Create" to launch the proposal, sign the transaction in your wallet and self-vote.

<figure><img src="../.gitbook/assets/image (72).png" alt=""><figcaption></figcaption></figure>

Once live, participate in discussions around your voting changes proposal. If the quorum is reached, the new parameters will go into effect after execution.

Use this template whenever you want to transfer Tokens from the Treasury to a Specific Address.
